# 小鲸 · Android AI 桌宠

住在手机上的 Q 版小鲸鱼：会说话、会听你说话、会自己刷视频。

## 功能

- **桌宠**：悬浮窗小鲸鱼，呼吸 / 眨眼 / 说话张嘴，可拖动
- **语音**：系统 TTS 说话 + 系统语音识别听你说话（中文）
- **大脑**：直连 DeepSeek API，SSE 流式回复，气泡逐字显示
- **记忆**：SQLite 存对话历史 + 长期事实，自动装配进上下文
- **自动刷视频**：无障碍读屏 + 手势滑动，双策略自适应
- **安全**：自动化总开关默认关闭，悬浮窗红色 ■ 一键停止，全部操作写日志

## 交互

| 操作 | 效果 |
|---|---|
| 单击小鲸 | 提示 |
| 双击小鲸 | 读屏并报出当前屏幕文字 |
| 长按小鲸 | 打开设置 |
| 点 🎤 | 开始/结束语音输入 |
| 点 ■ | 停止自动化 |

## 首次使用

1. 装好后打开「小鲸」
2. 第①步：开悬浮窗权限 → 开无障碍（系统设置里找「小鲸」）→ 授权录音
3. 第②步：填 DeepSeek API Key（`sk-` 开头）
4. 第③步：点「试听一句」确认 TTS 正常
5. 第④步：打开「自动化总开关」和「允许自动刷视频」
6. 点「▶ 开始刷视频」，回桌面看它干活

## 刷视频的两种模式

程序会**先读控件树**：

- 读到文字 → 模式「控件」，尝试点「下一条」按钮，找不到再滑
- 读不到（App 封锁无障碍）→ 自动降级「盲滑」，直接模拟手势上滑

每次翻页间隔带 ±25% 随机抖动，滑动时长 220~360ms 随机，避免过于规律。

## 构建

推送到 main 自动触发 GitHub Actions 编译，产物在 Actions → Artifacts → `whale-pet-apk`。

也可以本地：`gradle assembleDebug`
